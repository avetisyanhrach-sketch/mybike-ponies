# MYBIKE CREW – Ponies Wednesday Challenge

Автоматический рейтинг для mybike.la. Каждую среду система собирает с сегмента Strava
**Griffith Park Hill Climb (#966059)** результаты всех райдеров, стартовавших на сегменте с **6:00 до 9:00** по Лос-Анджелесу.

Что получается на сайте:
- **Weekly** — этап недели: место, имя, время старта, время, отставание.
- **Grand Tour** — месячный зачёт по правилам Nichols Ride: время всех этапов месяца суммируется, в зачёт попадают только те, кто проехал каждый этап.
- **Страница райдера** — история всех этапов, лучшее и среднее место, подиумы, лучшее время.

## Как это работает

```
GitHub Actions (по расписанию)
  └─ scripts/collect.mjs  → лидерборд сегмента на Strava (фильтр «Сегодня» / «Эта неделя»)
                           → только старты 6:00–9:00 в среду
                           → data/stages/ГГГГ-ММ-ДД.json
  └─ scripts/build.mjs    → docs/data.json (этапы, Grand Tour, райдеры)
GitHub Pages отдаёт docs/data.json
Секция Shopify на mybike.la читает data.json и рисует таблицы
```

Данные берутся из того же внутреннего запроса, которым пользуется сам сайт Strava, когда вы открываете лидерборд сегмента.
Нужна сессия Strava-аккаунта с подпиской: фильтр по датам в лидерборде платный.

Расписание запусков (идемпотентно: повторный запуск ничего не дублирует):

| Когда (LA) | Что делает |
|---|---|
| Ср ~9:30–10:30 | первый сбор после окна 6–9 |
| Ср днём | подхватывает поздние загрузки |
| Ср ~22:30–23:30 | последний сбор в сам день |
| Чт | догрузка через фильтр «Эта неделя» |
| Вс | финальная догрузка до закрытия недели |

## Установка (один раз, ~20 минут)

### 1. GitHub
1. Создайте **публичный** репозиторий, например `mybike-ponies`, и загрузите туда все файлы проекта.
2. **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main`, папка `/docs`.
   Адрес данных будет: `https://<ваш-логин>.github.io/mybike-ponies/data.json`.
3. **Settings → Actions → General → Workflow permissions**: *Read and write permissions*.

### 2. Сессия Strava (секрет `STRAVA_COOKIE`)
Лучше завести отдельный Strava-аккаунт клуба с подпиской, а не использовать личный.
В его настройках поставьте часовой пояс **Pacific Time**: фильтр «Сегодня» считается по часовому поясу аккаунта.

1. Войдите в этот аккаунт в Chrome и откройте https://www.strava.com/segments/966059
2. Откройте DevTools (F12) → вкладка **Network**.
3. В лидерборде выберите фильтр **Today**. Появится запрос `leaderboard?filter_type=all&date_range=today…`.
4. Кликните по нему → **Headers → Request Headers → cookie** → скопируйте значение целиком.
5. В GitHub: **Settings → Secrets and variables → Actions → New repository secret**,
   имя `STRAVA_COOKIE`, значение — скопированная строка.

Если Strava сбросит сессию (выход из аккаунта, смена пароля), запуск упадёт с сообщением
«Strava session rejected» и GitHub пришлёт письмо. Тогда повторите шаги 1–5.

### 3. Shopify (mybike.la)
1. **Online Store → Themes → … → Edit code**.
2. В папке **Sections** создайте `ponies-challenge.liquid` и вставьте содержимое `shopify/sections/ponies-challenge.liquid`.
3. В папке **Templates** создайте шаблон страницы `ponies-challenge` (JSON) и вставьте `shopify/templates/page.ponies-challenge.json`.
4. **Online Store → Pages → Add page**: заголовок «Ponies Wednesday Challenge», шаблон `page.ponies-challenge`.
5. **Customize** → откройте эту страницу → секция *Ponies Challenge* → вставьте адрес `data.json` из шага 1.2.
   При желании укажите email для просьб об удалении.

### 4. Первый запуск
**Actions → Collect Ponies Wednesday results → Run workflow.**
Пока не прошло воскресенье, можно забрать и прошедшую среду: поле *date* = `2026-10-14`.
Более старые недели Strava через фильтры уже не отдаёт, поэтому история начинается с первого запуска.

## Обслуживание
- **Убрать райдера по его просьбе**: добавьте его Strava ID (число из ссылки на профиль) в `data/excluded.json`,
  например `["36901812"]`, и запустите workflow вручную.
- **Поменять окно, день или сегмент**: `scripts/config.mjs`.
- **Проверка кода**: `npm test` (прогон на тестовых данных, без обращения к Strava).

## Ограничения
- Лидерборд Strava показывает **одну лучшую попытку райдера за день**. Если в среду человек проехал подъём дважды
  и быстрее был заезд вне окна 6–9, его попытка в окне не видна и не попадёт в рейтинг.
- Райдеры, скрывшие себя из лидербордов или сделавшие заезд приватным, не попадают в рейтинг. Это правильно.
- Способ не является официальным API Strava. Strava может изменить внутренний запрос или ограничить аккаунт;
  тогда понадобится обновить `scripts/collect.mjs`.
